# afterquiet.app

Public design document for Afterquiet: a closed-loop search for the sound that gives the deepest and longest residual inhibition of tinnitus.

`page.html` is the source; `python3 build.py` inlines the SVGs from `fig/` into `index.html`. The data figures in `fig/` are generated by the (private) app repo with `uv run python -m sim.site_figures fig`. Plain static HTML served by GitHub Pages at https://afterquiet.app (CNAME). afterquiet.org redirects here through a Cloudflare redirect rule.

Preview locally:

```bash
python3 -m http.server 8790
```
